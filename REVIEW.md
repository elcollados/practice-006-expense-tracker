const/let, stores a value, const can't be reassigned/change the value, let can.
function, block of code you can run many times.
return, sends a result out of a function.
if/===, runs code when a condition is met/True, === check if two values are equal.
array, a list of items inside [].
object, each object is one item in array, {}.
.push(), adds an item to the end of an array.
DOM, how JavaScript talks to the HTML page.
getElementById / querySelectorAll, finds elements on the page.
.value, the text inside an input.
addEventListener, runs a function when something happens, like a click, input.
callback, a function you give to another function, call using the function name. 
.forEach(), goes through each item in an array.
.filter(), keeps only the items that meet the condition(true).
.find(), returns the first item that matches.
.reduce(), combines all items into one value.
createElement, makes a new HTML element and appendChild puts it on the page.
textContent, sets or reads the text of an element.
Number(), turns text into a number, Inputs always give text.
localStorage, saves data in browser so it stays after refresh, it only stores text.
JSON.stringify/JSON.parse, stringify turns an array or object into text, parse turns it back.
||(or), uses the right side if the left is empty.
dataset, reads a data- attribute from HTML.
prompt(), shows a popup that ask the user to type something.
Date.now(), the current time as a number. 
fetch, gets data from a website's API.
async/await, await wait for slow things like fetch to finish, await only works inside an async function.
try/catch, runs risky code. if it fails, catch runs instead of crashing.
.toFixed(2), rounds a number to 2 decimal places.
