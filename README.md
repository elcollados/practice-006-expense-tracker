# Expense Tracker

A simple web app to record daily expenses, built with plain HTML, CSS, and JavaScript.

## Features

- Add an expense with a title, amount, and category (Food, Transport, Bills)
- Edit and delete expenses
- Filter the list by category
- Shows the total of the visible expenses in PHP
- Converts the total to USD, EUR, or JPY using live rates
- Saves data in the browser (localStorage), so it stays after refresh

## Technologies

- HTML
- CSS
- JavaScript
- [Frankfurter API](https://frankfurter.dev) for currency rates

## What I learned

- DOM manipulation
- Array methods: `filter`, `find`, `reduce`, `forEach`
- Saving data with localStorage
- Fetching data from an API with `fetch` and `async/await`
